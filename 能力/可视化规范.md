# 今日总览 · 可视化规范（VISUAL\_SPEC）

> 这份文档是"每日总览"渲染的**唯一权威规范**。渲染器（`tools/渲染今日.mjs`）每次只做两件事：
> **读数据端口 → 按本规范渲染出"今日.html"**。不要在这里之外另写一套视觉规则。

***

## 0. 核心原则

1. **一个超大模板，按数据自适应裁切**：模板预置了所有板块，但**某板块当天没有数据就不渲染该板块**。宁可留白，不展示空卡。
2. **只读数据端口**：唯一事实源是 各数据文件夹内的JSONL/JSON文件（活跃任务在「待办任务」文件夹，归档任务在「待办任务/待办任务：已归档」）。渲染器不改任何数据。
3. **移动端优先**：手机直接打开即清晰可读，自包含单 HTML（内联 CSS，无外链）。

***

## 1. 视觉风格（沿用个人偏好）

* **背景**：浅灰 `#F2F3F7`，大量留白。

* **卡片**：白色圆角矩形 `border-radius: 20px`，**无描边、无半透明方框边**，仅一层极轻投影 `0 4px 14px rgba(15,23,42,.06)`。所有卡片统一此样式。

* **配色**：2 个主色 + 黑白灰。

  * 主色A（绿）#2FB26B → 用于标题强调、正向/进行中

  * 主色B（靛蓝）#5B6CFF → 用于次级强调、链接/选中

  * 中性：黑 #111827 / 次灰 #6B7280 / 弱灰 #9CA3AF

* **事件语义色**（用于任务/状态点）：进行中=绿 #2FB26B，将要发生=红 #EF4444，未来=黄 #F5B50B，已完成=灰 #D1D5DB。

* **字体**：系统字体栈 `system-ui, -apple-system, "PingFang SC", sans-serif`。层级清晰：板块标题大写小字弱灰，数值加粗放大。

* **头部**：顶部一卡，白→微灰的柔和渐变，显示日期/星期 + 当日最关键的指标。

***

## 2. 板块清单与自适应规则

> 每个板块独立渲染，无数据则整体不出现。`mode` 决定取数窗口：

| 板块            | 简述           | 取数规则                 | 无数据时的表现  |
| ------------- | ------------ | -------------------- | -------- |
| **头部 Header** | 日期·星期·当日关键指标 | 全天                   | 始终显示     |
| **今日支出**      | 当日全部支出，按分类聚合 | `expense` + 日期=今日    | 无支出则隐藏   |
| **睡眠**        | 昨晚/当天睡眠      | `activity` 中 `category` 含「睡眠」的时段，日期=昨晚或今日 | 无则隐藏     |
| **体重**        | 今日体重，含较上次变化  | `weight`，日期=今日或最近7天  | 无则隐藏     |
| **运动**        | 当日运动         | `exercise` + 日期=今日   | 无则隐藏     |
| **任务/提醒**     | 今日到期的提醒/待办   | `tasks`，remindDay=今日 | 今日无到期则隐藏 |
| **月度支出**      | 本月累计支出       | `expense` + 日期∈本月    | 本月无支出则隐藏 |

**mode 语义**

* `morning`（早9点）：看"昨天的回顾 + 今天该做什么"——睡眠取昨晚、体重取今早、突出任务/提醒。

* `evening`（晚10点）：看"今天全天收账"——支出/运动取今日全天、体重取今早。

* `full`（默认/预览）：尽量聚合今日全部维度。

字段标签与单位一律从各数据文件夹内的「*：类型配置.json」读取（如 `weight.unit=kg`）。

***

## 3. 板块内部形态

* **今日支出**：顶部一行"今日支出 合计 ¥xxx"；下方每类一行：语义色圆点 + `一级分类/二级分类` + 金额 + 笔数。配色圆点按一级分类取固定色板。

* **睡眠**：从 `activity`（`category` 含「睡眠」）取时段，大数字"8 h" + 入睡/醒来时间；有 `quality` 显示质量文案。

* **体重**：大数字"68.4 kg" + 相对上一次的差值（+0.3 / −0.5），绿色升/与中性。

* **任务**：语义色状态点 + 标题 + 触发日期；已完成置灰。

***

## 4. 输出与命名

* 输出目录 `reports/`。

* 命名：`today.html`（当天实时版，渲染器每次覆盖）、`<YYYY-MM-DD>.html`（按日归档，可选）。

* 渲染命令：`node tools/渲染今日.mjs [--date YYYY-MM-DD] [--mode morning|evening|full] [--out <path>]`
